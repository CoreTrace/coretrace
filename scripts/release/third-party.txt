# The third-party code the Linux release archives ship, and where its license is. One line per
# group of files: a glob relative to the archive root (`*` also matches `/`, and the first line
# that matches a file applies to it), then the licenses of what those files contain, each a file
# or a directory relative to the archive root.
#
# check-licenses.sh fails the packaging, and every release verification, when a shared library
# or an executable of the archive matches no line, or when a license named by a matching line is
# missing. A new dependency, another LLVM or another base image therefore fails until its license
# is reviewed and its line added or updated here.
#
# Where the licenses come from:
#   <...>licenses/<distribution>/<package>  collect-licenses.sh copies them from the package
#       database of the image that built the files, with the package's exact VERSION, after
#       checking that the package provides each shared library of the line;
#   licenses/<component>  installed by CMake from the sources compiled into ctrace;
#   the others  shipped by the bundled tools, or copied with them (Dockerfile.release-binaries).
