# The third-party code the macOS release image ships, and where its license is, in the format of
# third-party.txt (the Linux archives' inventory): a glob relative to the image's folder, then the
# licenses of the files it matches. check-licenses.sh fails the packaging when a library or an
# executable matches no line, or when a license a matching line names is missing.
#
# Where the licenses come from:
#   <...>licenses/homebrew/<formula>  collect-licenses.sh brew copies them from the formula's keg
#       on the machine that built the image, with the keg's VERSION, after checking that the keg
#       has each shipped library of the line;
#   licenses/<component>  installed by CMake from the sources compiled into ctrace;
#   the others  shipped by the bundled tools (scripts/build-python-analyzer.sh).

# ctrace, and the code compiled into it.

config/models/*  licenses/coretrace-stack-analyzer

lib/clang/*/include/*  licenses/homebrew/llvm@20
